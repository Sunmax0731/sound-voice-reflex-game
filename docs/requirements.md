- 代表シナリオ4種を自動検証する。
- GitHub Pagesまたはローカルサーバーで起動できる静的Webゲームとして、非blank表示と主要操作を必須とする。
- 文字化けを検出し、正式成果物へ残さない。
- QCDSの10段階スケールを機械検証する。
